# Security Policy

## Supported Versions
Active security patches are provided for the primary release on the `main` branch.

## Security Architecture Highlights
- **Cryptographic Audit Ledger**: Tamper-evident SHA-256 block chain securing all placement actions.
- **Tenant Isolation**: Row-level tenant boundaries separating institutional data.
- **Data Privacy**: India DPDP Act 2023 compliant read-only repository scanning with explicit student consent.

## Reporting a Vulnerability
If you discover a security issue or vulnerability within this platform:
1. Please do not open a public issue.
2. Send a report with technical details and reproduction steps to the repository maintainers.
3. We will review and provide an initial response within 48 hours.
